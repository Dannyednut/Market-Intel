# Market Intel

Continuous multi-agent market intelligence research program. NOT a software project — this repository is the **intelligence archive**: cycle briefs, verified findings, analysis chains, and strategy constructs, produced by an orchestrated agent swarm (Research → Discovery → Analysis → Engineering) in long work sessions.

**Mandate:** multi-market — fintech, exchanges, and the cross-market infrastructure between them (stablecoins, RWAs, custody, macro-capital flows), with emerging-market (Africa-first) coverage as a standing focus.

## How the program runs

1. **Ping** — the user triggers a work session ("continue" / "run cycle").
2. **Wave 1 — Research**: parallel agents scan the mandated landscapes via live web search; findings are cross-checked and confidence-graded.
3. **Wave 2 — Discovery / Analysis / Engineering** (parallel on the same evidence): whitespace mapping, structural problem identification, strategy construction.
4. **Synthesis**: the orchestrator merges everything into a PDF + markdown brief.
5. **Archive**: all role outputs are committed to this repository; the worklog carries program memory to the next cycle.

## Archive structure

```
briefs/      Cycle intelligence briefs (PDF + markdown twin)
findings/    Research findings bank, discovery map, analysis, strategy cards per cycle
assets/      Cover and document sources
worklog.md   Program memory: agent assignments and outputs per cycle
```
